# Configuración de Red con Cisco Packet Tracer

Proyecto académico desarrollado en **Cisco Packet Tracer** para configurar una red con múltiples routers, switches y dispositivos finales, logrando conectividad entre las diferentes redes mediante direccionamiento IPv4 y enrutamiento estático.

## Descripción

El proyecto consiste en realizar las configuraciones necesarias para establecer conectividad completa entre diferentes segmentos de red.

Se configuraron routers, switches y dispositivos finales utilizando direccionamiento IPv4, máscaras de red, gateways y rutas estáticas.

## Configuraciones realizadas

### Routers

- Configuración de nombres de los routers.
- Configuración de direcciones IPv4 en las interfaces.
- Configuración de máscaras de red.
- Configuración de enlaces seriales.
- Configuración de reloj de sincronismo (Clock Rate).
- Configuración de enrutamiento estático.
- Conectividad entre redes externas.

### Switches

- Configuración de nombres.
- Configuración de VLAN 1.
- Configuración de dirección IP de administración.
- Configuración del Gateway.
- Configuración de acceso remoto mediante VTY.
- Configuración de contraseñas para acceso privilegiado, consola y VTY.

### Dispositivos finales

- Configuración de direcciones IPv4.
- Configuración de máscaras de red.
- Configuración de Gateway.
- Verificación de conectividad dentro de la red.

## Tecnologías y conceptos

- Cisco Packet Tracer
- IPv4
- Subnetting
- Direccionamiento IP
- Routers y switches
- Enrutamiento estático
- VLAN 1
- Interfaces
